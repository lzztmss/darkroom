# ADR 0005：作者线索识别不阻塞首轮专业点评

状态：接受（本地 MVP 规划）  
日期：2026-09-24

## 决策

照片先完成盲评和专业评价。作者或作品线索识别作为可选的语境 pass，不参与任何维度分数，也不能覆盖首轮观察事实。

只有在具备授权摄影师目录、作品元数据或用户主动提供的语境时，才返回 `identified` 或 `possible`。没有可核验证据时返回 `unknown` 或 `not_assessed`。

## 延迟与成本

如果作者线索识别与主评价串行，会增加一次模型往返时间；如果与主评价并行，首屏等待时间通常接近两次请求中较慢的一次，但模型调用成本和限额消耗会增加。首轮 MVP 默认关闭并行 pass，避免用不可靠的风格猜测影响用户信任。

## 后续实现条件

1. 建立公共领域或已授权的摄影师、系列和作品目录；
2. 用独立的作者识别评测集记录 `identified / possible / unknown` 的精确率和误报率；
3. 在结果页用“作者线索”标签展示，并明确这是语境提示，不是鉴定结论；
4. 作者识别失败不改变专业评分，也不把文件名、EXIF 或用户输入的作者名当作模型证据。
