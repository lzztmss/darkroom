# ADR 0005：作者识别先行并以小幅上限影响点评

状态：接受（本地 MVP 规划）  
日期：2026-09-24

## 决策

照片分析启动独立的作者与作品线索识别，并与专业评价并行执行。识别结果只用于作者声音的语境判断，不覆盖可观察事实；只有 `identified` 且置信度达到 0.82 时，才允许影响总体分数，修正上限为 ±3 分。

没有多项相互印证的视觉证据时返回 `possible` 或 `unknown`。授权摄影师目录、作品元数据或用户主动提供的语境可以作为后续核验来源，但不能替代视觉证据。

## 延迟与成本

作者识别使用独立的短视觉识别请求，与完整点评请求并行执行，避免增加一整轮等待；结果只在有多项视觉证据时标记为 `identified`，否则保留为 `possible` 或 `unknown`。识别结果写入综合参考，不在结果页增加单独的作者栏目；它仍不能把未核验的风格相似写成确定作者。

## 后续实现条件

1. 建立公共领域或已授权的摄影师、系列和作品目录；
2. 用独立的作者识别评测集记录 `identified / possible / unknown` 的精确率和误报率；
3. 在结果页用“作者线索”标签展示，并明确这是语境提示，不是鉴定结论；
4. 作者识别失败不改变专业评分，也不把文件名、EXIF 或用户输入的作者名当作视觉证据。
