# ADR-0002：隐私优先的照片生命周期

状态：接受
日期：2026-07-22

## 背景

摄影照片可能包含人脸、住所、未成年人、位置和拍摄设备信息。用户选择本产品的重要原因之一是羞于公开投稿，因此默认私密必须体现在数据架构中，而不仅是隐私政策文字。

## 决策

1. 上传照片默认私密，只有本人可访问。
2. 原始上传文件仅用于生成分析所需预览，在分析完成后24小时内自动删除。
3. 历史记录保留最长边不超过2048像素、已移除精确 GPS 的预览图，直至用户主动删除账户或该条记录。
4. 系统可读取相机、镜头、焦距、光圈、快门和 ISO 用于分析，但不保存精确定位信息。
5. “公开分享到社区”“用于改进模型”“生成式教学模拟”是三个独立开关，均默认关闭。
6. 删除操作必须清除数据库记录、对象存储文件和可定位的派生资源；备份按既定保留周期淘汰。
7. 未经单独评估与授权，不将照片发送到境外模型服务。

## 结果

- 产品需要原件与预览分离的对象存储路径。
- 所有公开内容必须具有明确授权记录。
- 模型日志不得包含图片二进制、永久公开 URL 或完整 EXIF。
- 端到端删除流程是 MVP 的阻断级测试项。
