# ADR-0001：国内模型与供应商抽象

状态：接受
日期：2026-07-22

## 背景

产品面向中国大陆公众，处理用户上传的照片与可能的个人信息。OpenAI API 未在中国大陆提供官方支持，境外处理还会增加服务稳定性和个人信息出境负担。

## 决策

1. 中国大陆生产版本优先调用已备案、可在境内稳定提供服务的视觉模型。
2. 第一轮评测至少比较阿里云百炼 Qwen-VL 与火山方舟豆包视觉理解。
3. 所有模型通过统一 `ModelGateway` 概念接口调用；业务层只依赖内部请求与响应 schema。
4. 模型选择基于固定摄影评测集、响应时间、单位成本、数据政策和备案状态，不基于品牌宣传。
5. 保留未来接入其他国内模型、自托管开源模型和独立国际版本的能力。

## 结果

- 首版开发增加一层适配器与结构化输出校验。
- 不能使用供应商专属返回格式作为核心数据模型。
- 供应商切换和双模型复核成为可测试能力。
- 每个生产模型必须记录名称、版本、备案信息、数据位置和成本。
