# 产品路线图

路线图采用验证门槛，不以日期替代产品证据。

## 阶段0：项目正式化

交付：项目书、设计规格、路线图、ADR、协作规则和 Git 仓库。

退出条件：项目发起人批准设计规格并进入实施计划。

## 阶段1：交互原型

交付：上传、填写意图、分析结果、图上标注、裁切方案和反馈的可点击界面；使用固定样例数据，不调用真实模型。

退出条件：5名目标用户能够在无讲解情况下完成流程，并能复述产品与普通 AI 点评的区别。

## 阶段2：功能 MVP

交付：邀请制账户、图片上传、国内视觉模型网关、结构化点评、照片生命周期、历史记录和反馈采集。

退出条件：内部评测集通过；不存在阻断级隐私、权限或数据删除缺陷。

## 阶段3：封闭测试

交付：30—100名真实用户、反馈面板、成本监控、模型回归评测和人工抽检流程。

退出条件：达到项目书中的复用率、帮助度和重拍行为指标，且单次分析成本可支持预期定价。

## 阶段4：审美档案与轻社区

交付：收藏偏好、个人审美特征、选择性公开、每周主题、结构化互评、创作声望与点评声望分离。

退出条件：社区内容供给和有效点评不依赖创始人每日人工补充。

## 阶段5：可控后期与专业内容

交付：更完整的传统后期参数、参考风格分析、授权摄影师专题、专业点评合作和 RAW 技术验证。

退出条件：用户明确需要这些能力，授权链路和单位经济模型成立。

## 阶段6：垂直模型能力

交付：基于合法、授权、高质量摄影反馈数据的检索增强、排序模型或视觉模型微调。

退出条件：通用模型加知识库已成为效果瓶颈；已有足量且经过质量审核的训练与评测数据。
